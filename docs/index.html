  • 多数企业被动继承传统专业性规范，忽视了主动塑造职场文化的权力与责任
  • 不合理的专业性标准（外表、沟通方式等）常以排斥性方式系统化歧视少数群体
  • 有效的专业性应从组织成功目标、核心价值反推，而非教条式沿袭

How Claude Mythos found a 15-year-old bug in Mozilla Firefox | Brian Grinstead

Mozilla 工程师 Brian Grinstead 分享如何用 Agent 驱动的 bug 发现管道改造 Firefox 开发流程。关键发现：单个 LLM 模型不到一半的功劳，自定义检测框架（harness）、验证子 Agent、目标循环反馈与现有 CI/模糊测试工具的整合同样重要。这套方法论可迁移到设计质量、转化率优化等非工程领域。但 AI 生成补丁仍需人工审核，不能自动上线。展示了 Agent 在大规模代码库优化中的实际落地与团队协作模式。

  • Agent 效果 50% 来自模型，50% 来自管道设计——验证、评分、重试机制是关键
  • LLM 评判器预筛文件避免盲目遍历，降低计算成本；验证 Agent 消除误报
  • 现有 CI/Fuzzing 投资是加速器；AI 补丁最终需人工审核，不可全自动化
  • 紧凑目标、清晰通过/失败信号、容错重试是 Agent 高效运作的三要素
