Agents are sessions, not requests: size GKE node pools for AI agent sessions

Google 分享 AI Agent 工作负载在 Kubernetes 上的资源优化实践。传统一个 Pod 对一个会话的模式导致资源浪费，因为 Agent 会话大部分时间处于空闲状态。通过 Agent Substrate 和 AX 等开源工具，可将空闲会话状态存入对象存储，释放计算资源，同时保留会话上下文，从而降低 GKE 节点成本至多 40%。这反映了 Agent 作为长连接工作负载对基础设施和成本模型的新要求。

  • Agent 会话长时间空闲，传统按需分配 Pod 造成资源浪费与成本高企
  • 通过会话状态持久化到对象存储，可释放计算资源同步降低成本 40%
  • 需要重新思考 Kubernetes 资源池规划，适应 AI Agent 长连接特性
  • 开源工具链（Agent Substrate、AX）提供可行的工程化解决方案

How I fight token fraud as a solo founder

ChatPRD 创始人 Claire Vo 分享了 AI SaaS 企业面临的「代币欺诈」问题——过去一年损失数万美元，耗尽工程资源。她详细阐述了六种滥用模式（免费试用农业、转售促码、中继包装、自定义 MCP 计算农场等），以及采取的业务与技术防控措施（关闭免费试用、实时欺诈分类、Jev 自动监测）。核心洞察："如果你出售 AI，你出售的就是计算资源"——这使得 AI SaaS 企业成为独特的攻击目标。内容兼具实战价值和组织运营启示。

  • AI SaaS 因出售计算资源而面临代币欺诈风险，远超传统 SaaS
  • 六种主要滥用模式：免费试用农业、转售促码、中继包装、MCP 农场、支持向量攻击、账户滥用
  • 业务控制优于技术防御：关闭免费试用、严格身份验证、支付验证、地理限制等
  • 技术防御：Jev 实时欺诈分类、Stripe Radar、Vercel 防火墙、自动监测 bot
  • 警示：支持系统可成为攻击向量，需要在开放与安全之间平衡
