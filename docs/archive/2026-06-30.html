No Figma. No Jira. No docs. How Gusto built a new product line with Claude Code | Eddie Kim (CTO)

🎙️ How I AI: GLM-5.2 review & How Gusto built a new product line with Claude Code

本文评测GLM-5.2开源模型在实际代码工作流中的表现。核心观点：开源权重模型已成生产级替代品，不再是爱好者玩具。GLM-5.2性能接近Claude Opus，成本仅为其零头，关键优势在于成本、自主控制和避免厂商锁定。作者通过45分钟自主bug排查任务测试，发现其HTML/CSS可靠，React处理不够稳定。建议将其与闭源模型搭配使用，而非完全替代，适合长上下文任务和成本敏感场景。反映了AI工具在工程团队中的选型权力转移。

  • 开源模型已达生产级质量，自托管改变了厂商议价关系，规避单一供应商依赖
  • GLM-5.2成本仅$3.36/600万tokens，为闭源模型的fraction，特别利于长上下文Agent任务
  • 实测表明HTML/CSS生成可靠，React多步Agent任务稳定性仍需验证，是采用前必测关键
  • 开源模型降低了技术选型的锁定风险，团队可自由切换推理供应商，无需改动应用代码
