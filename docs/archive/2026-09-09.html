8/10 · MIT Sloan Management Review · 商业 · 2026-09-08
Responsible AI Means Knowing the Limits of Agent Autonomy

MIT Sloan 和 BCG 的国际 AI 专家小组研究了 AI Agent 治理的核心悖论：72% 专家同意「将 Agent 视为自主决策者的治理会失败」。虽然 Agent 在操作层面展现自主性（可独立执行、规划、调用工具），但这种技术自主性不等于道德或法律责任。关键洞见是：将 Agent 标签为「自主」会导致背后的人类和机构逃避责任。有效治理应将每个重要决策溯源到具体可追责的负责主体，而非将责任推给算法。这对企业组织如何定义 AI 赋权、人机协作边界、以及风险承担方式产生深刻影响。

  • 72% 专家认为将 Agent 当自主决策者的治理模式会失败，责任归属不明成致命风险
  • Agent 具备操作自主性（独立执行、工具调用），但这不等同于道德或法律责任主体
  • 有效治理需将决策权溯源至具体可问责的人类和机构，而非模糊为「AI 自主」
  • Agent 本质是「委托执行」—— 在人类设定的目标和护栏内运作，并非真正自主
  • 企业需重新定义人机协作边界，避免责任逃避，建立端到端的问责链
