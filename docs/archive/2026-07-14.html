🎙️ How I AI: GPT-5.6 review, How a solo builder runs 24/7 local AI, and What an agent harness is and how to build one

本期播客聚焦 AI Agent 在实际工作场景中的应用。核心议题包括：(1) "Harness"（框架/围绕层）的概念与构建——即围绕 AI Agent 的定制代码，用于特定任务的自动化；(2) 以 ChatPRD 的 Sentry bug 分类自动化为例，演示如何通过约束权限、自定义工具适配器、结构化输出等方式，让 Agent 输出更一致、更廉价、更可控；(3) 强调专用 Harness 优于通用工具（Claude Code）的优势：多模型路由、权限编码、工作流固化。反映了 AI 在工程团队中从「开放式助手」向「特定任务自动化引擎」的演变方向。

  • Harness 是围绕 AI Agent 的定制代码层，用于固化重复性工作流和权限约束，而非神秘概念
  • 专用 Harness 通过自定义工具适配器、权限编码、结构化输出，相比通用 Agent 更快更廉价
  • 识别「部分确定性+部分非确定性」的任务是构建 Harness 的关键触发点
  • 通用 Agent 的新角色是编排多个专用 Harness，而非直接执行所有任务

How GenAI Can and Can’t Help Manage Customer Insights

MIT Sloan 探讨生成式 AI 如何改进客户洞察管理。关键发现：企业不应只关注知识存储/访问，而要重新设计知识流程（创建、分析、存储、获取）。P&G 等公司通过 RAG 技术整合内部数据与 LLM 能力，员工可用自然语言快速获取洞察。但组织孤岛、文化障碍等旧问题仍存在。文章强调技术赋能需配合流程优化和跨部门协作，否则 GenAI 只是新瓶装旧酒。

  • GenAI 不只是搜索工具，应重设知识流程，从创建到访问全链路优化
  • P&G 用 RAG+自研分析系统获得「锐利答案」而非文档链接，体现深度应用
  • 组织孤岛、文化阻力比技术本身更大，需流程与协作升级配合
