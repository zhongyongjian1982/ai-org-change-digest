8/10 · MIT Sloan Management Review · 商业 · 2026-07-23
Robots Are Coming — but Not Everywhere

MIT Sloan 的研究挑战了「人形机器人采用曲线将复制生成式AI爆炸式增长」的预期。研究发现，人形机器人会沿着更复杂、不均匀的路径扩展。原因包括：（1）不存在通用模型——不同角色（仓储、护理、安保等）对机器人的物理、软件、计算架构要求差异巨大，导致制造商走向专业化而非通用化；（2）地理差异巨大——ROI 强劲的「可行性岛屿」集中在劳动力成本高、短缺严重的特定地区；（3）部署速度取决于具体应用场景。领导者需要调整战略，为分化的、多轨道的机器人应用做准备。

  • 人形机器人不会成为通用工具，而是按角色专业化——仓储、护理、安保需要完全不同的硬件与软件架构
  • 采用集中在「可行性岛屿」：高劳动力成本+短缺+基础设施完善的特定地区，全球推广不均衡
  • 各制造商按市场细分专业化，机器人形态多样（双足、轮式等），扩展速度因用例而异
  • 企业领导需要放弃「AI 式快速普及」的假设，为长期、分化的部署路径规划

8/10 · One Useful Thing (Ethan Mollick) · 分析师 · 2026-07-24
An opinionated guide to which AI to use to do stuff

Ethan Mollick 阐述了 AI 工作方式的根本转变：从对话式chatbot 演进到 Agent 系统，使 AI 获得了「计算机」和规划执行能力，能在数小时内完成相当于人类多小时的工作。文章基于最新模型能力对比，给出了不同场景的选择建议：低风险咨询用免费模型；高风险决策需用最强模型；真实工作需订阅 Claude/ChatGPT 的 Agent 模式。这反映了 AI 从工具向自主执行系统转变对知识工作方式的重塑。

  • Agent 系统赋予 AI 计算机访问权限，能规划和自主执行工作，改变了人工作流程
  • 高风险决策需用最强模型；低风险查询可用免费模型，体现分层赋能策略
  • Claude/ChatGPT 订阅制 Agent 模式成为知识工作实践的核心工具，需配置应用权限
  • 模型思考深度（Thinking Level）成为质量关键变量，影响复杂领域输出准确率
