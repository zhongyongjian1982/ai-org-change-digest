HTML is the new Markdown: How Anthropic engineers are building with Claude Code | Thariq Shihipar

Anthropic 工程师 Thariq Shihipar 分享了用 HTML 替代 Markdown 作为 AI Agent（Claude Code）规划与实现工作流的新范式。核心发现：富视觉格式相比纯文本能显著提升人机协作效率。他介绍了通过 HTML artifacts 创建交互式计划、快速原型 UI、维护活态设计系统等具体做法。重点观点包括：99% token 应投入规划与接口设计而非生产代码；HTML 约束让 Claude 既有灵活性又能确保可控性；复杂度需「赚取其位置」。这反映了 AI 时代工作流从文本驱动向可视化、交互式范式的演进。

  • HTML 作为 AI Agent 通信格式，比 Markdown 提供更高视觉参与度和交互能力
  • 99% AI token 用于规划、界面、沟通，仅 1% 用生产代码——根本性改变开发优先级
  • HTML 规范与设计系统随代码库流动，实现活态文档，减少信息割裂
  • "复杂度需赚取其位置"——通过约束提示词让 AI 既自由又可控
